# MyPortfolio

## Overview

MyPortfolio is my personal portfolio website developed using React. It showcases projects, skills, and experiences, providing visitors with insights into my professional journey.

## Features

- **About Me**: Brief summary of my work experience and my current tech stack, skills and interests.
- **Project Showcase**: Highlights key projects with descriptions and links.
- **Experience**: Showcases my professional experience and significant responsibilities.
- **Contact**: Allows visitors to get in touch directly.

## Prerequisites

Before running the project, ensure you have:

- **Node.js** (version 12 or higher)
- **npm** (version 6 or higher)
